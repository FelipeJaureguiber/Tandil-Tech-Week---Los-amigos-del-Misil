# Tandil Tech Week - Reglas y Contexto del Proyecto

## Descripción
Landing page oficial para el evento **Tandil Tech Week**. La web debe ser moderna, interactiva, rápida y responsiva.

## Stack Tecnológico Obligatorio
- **HTML5**: Estructura semántica, limpia y accesible (sin frameworks pesados ni código generado por navegadores).
- **CSS3**: Hoja de estilos `style.css` moderna (CSS Grid, Flexbox, variables CSS, animaciones suaves).
- **JavaScript (vanilla / JS)**: Archivo `main.js` para interactividad dinámica, manipulaciones del DOM y efectos de navegación.
- **Sin dependencias basura**: Prohibido incluir scripts de terceros, analíticas externas o archivos minificados que no aporten valor directo.

## Objetivos de Diseño e Inspiración
- **Sitio base**: Inspirarse en la información y estructura de https://www.tandiltechweek.com/.
- **Nivel estético y UX**: Tomar como referente la calidad visual, microinteracciones y efectos de https://www.awwwards.com/ (animaciones fluidas, scroll suave, diseño visual impactante).

## Secciones Requeridas
1. **Header / Navbar**: Navegación fija con efecto blur o cambio al hacer scroll (vía JS).
2. **Hero Section**: Título impactante, fechas del evento, contador regresivo dinámico (vía JS).
3. **Cronograma / Eventos**: Tarjetas interactivas o pestañas para explorar actividades (Hacking Day, Startup Day, etc.).
4. **Sponsors / Acompañan**: Grid moderno con efectos de hover.
5. **Formulario de Contacto / Registro**: Validación en tiempo real mediante JavaScript.
6. **Footer**: Enlaces a redes sociales y créditos del equipo.
